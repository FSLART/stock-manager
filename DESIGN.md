# Stocklart design system

## Product and mode

Operate: a shared workspace for the LART team, used in the workshop on PCs and phones. Lead with tools and real data. The approved home is a shared-tools hub; department resources appear when real maintained destinations exist.

## Identity

Keep the LART mark, warm dark surfaces, yellow accent, real team photography and authentic engineering artifacts. The home uses a compact team introduction and two tool lists: Recursos e oficina and Engenharia. Purchasing is shown according to existing permissions. No promotional carousel, fictional activity or empty department dashboards.

## Tokens and typography

Background #20211f; panel #292a27; sidebar #181914; text #f4f2e9; secondary #a7a99e; borders #454740; accent #ffd400; accent text #181914. Main UI DM Sans, headings/brand Bricolage Grotesque, system fallbacks. Functional secondary type 12–14px; ordinary interface 14–16px; page titles 26–32px; home 32px mobile/44px desktop. Specialist diagrams can use engineering color/monospace to encode measurements and circuits.

## Composition

Compact global navigation with native anchor routes and two native disclosure groups. Account/preferences separate from task groups. Contextual breadcrumbs. Page content max1280px with 40px desktop/16–24px phone gutters. Home tool rows use separators rather than nested cards. Workspace panels have a single 1px border, 12px radius and no decorative shadow. Yellow indicates focus, useful emphasis and primary actions.

## Interaction and states

44px touch guidance; visible 2px yellow focus. Mobile menu supports Escape/return focus. Modified-click route links preserve browser behavior. Guard unsaved label drafts across global/hash navigation and native unload. State whether data is shared or device-local; show cached/pending/error information. Prefer explicit actions and native details for advanced settings. Keep empty/search/error recovery useful.

## Specialist tools

Harness shares the warm dark/yellow palette and interface scale. Search and choices precede detailed warnings; preserve diagrams and domain colors. Available BSPD simulation precedes planned boards. BSPD defaults to pt/dark while preserving saved explicit preferences. Its advanced calibration is disclosed separately from the test/result.

## Verification

Main surfaces at 1440px desktop and 390/320px phones; inspect native links, focus, drafts, read-only permissions, empty/error states and printing. Keep all data writes disabled during real-data visual inspection. Run frontend/build checks and harness tests/build. No deployment implied by a worktree build.
